# Bootlick Archive
*An archive of Trump's ["Arcade"](https://www.whitehouse.gov/arcade)*

**Build the wall** is not available on the live version of the website (probably due to a copyright complaint from the The Tetris Company). It also appears that, before being removed, the line clearing mechanic was disabled. The version archived here is reconstructed from Wayback Machine captures to include all functionality (both line clearing and mobile controls), and was also manually cleaned up to make the code readable.
